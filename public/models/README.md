# Nissan Silvia S15 (3D inspection model)

Download the GLB from Sketchfab and save it here as **`nissan-silvia-s15.glb`**:

https://sketchfab.com/3d-models/2014-rocket-bunny-nissan-silvia-s15-sema-build-b4ff35e673ed47ce952097af29de75ed

1. Open the link → **Download 3D Model**
2. Format: **glTF (.glb)**
3. Save/rename to: `public/models/nissan-silvia-s15.glb`
